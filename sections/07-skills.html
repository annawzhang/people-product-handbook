Markdown Python 标准库脚本 Cursor Agent Skills 目录规范

5. Best practices

  • description 写清 WHAT + WHEN，便于自动发现。
  • 默认 disable-model-invocation: true，重要 Skill 需显式点名。
  • 脚本可 --self-test；fixture 提交进仓。
  • Playbook 用检查清单，避免空泛原则。

6. Demo 路径

  1. 打开仓库 README 表格，对照各 Demo 链接。
  2. 跑材料审核 --self-test 与 fixture 批处理。
  3. 把 Skill 拷进 Cursor Skills 目录，对话点名试一次。
