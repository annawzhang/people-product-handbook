3. Follow-up

追问答法
市场规模会不会拍脑袋？漏斗每层在 TOML；改一层即可重算，强调「假设可审计」。
为什么不跟全网低价？P1 价格告警只跟核心 SKU；全面促销会打穿贡献与回本。
悲观情景还不成立怎么办？收缩可服务地理与补贴，而不是加码 CAC。
和真实 BP / 赛题什么关系？方法工具化练习；数据与品牌均为虚构，不上传真实 BP。

4. 技术栈梳理

项选择
依赖仅 Python 标准库（tomllib / pathlib / unittest）
配置TOML 案例包，行业可换
交付HTML 报告 + 7 项 unittest
刻意不用外部行情 API / Excel 宏（降低复现门槛）

5. Best practices

  • 先写清漏斗口径（TAM 含不含什么），再填数字。
  • 竞品告警分 P1/P2，汇报时只带「今日必做」。
  • 单位经济健康线：贡献>0 且回本 ≤ cap；否则先修毛利/履约再谈增长。
  • 三情景同屏：让评委看到下行纪律，而不是只讲乐观故事。

6. Demo 路径

  1. 打开报告：TAM → SAM → SOM 卡片，指一层假设。
  2. 竞品表 + P1 告警：份额/价格怎么应对。
  3. 单位经济：单均贡献与回本月。
  4. 情景表：悲观 vs 乐观 SOM；读评委追问包一条。
  5. python3 -m unittest discover -s tests -v（7 passed）。
