1. 能力层（VOC 专属）

L0
入口 · 对话页销售/策略侧提问；快捷芯片：价格关口 / 议题 / 话术 / 质检
L1
主调度 · VocAgent.answerdetectIntent：质检 > 话术 > 价格关口 > 议题检索
L2
Skill 白名单search · topicStats · priceCeiling · fourStep · checkScript
L3
原声证据议题语料 · 点赞加权 · citations 必填 · 无 cite 拒答
L4
治理 · Insight Kit跑批更新语料 · codebook / 禁止规则 · tests.html
公开复刻为规则引擎（无托管 LLM）；产品化挂模型时 Skill 边界不变。

4. Skill / API

调用层说明
VocAgent.answer(text)L1主入口；返回 blocks/citations 或 error
search / topicStatsL2议题检索与负面率
priceCeiling()L2负面点赞占比首次 ≥50% 的价位
fourStep(topic)L2认同→重构→转移→落地 + cite
checkScript(text)L2禁止话术命中列表

产品化 HTTP 建议

POST /v1/voc/query     { question } → { answer, citations[] }
POST /v1/voc/scripts   { topic, model } → { steps[], cite }
POST /v1/voc/moderate  { text } → { ok, hits[] }
POST /v1/voc/batch     { comments[] } → report_id

6. Follow-up

追问答法
和 98008 什么关系？两套独立全栈；方法上可对照「入口/调度/Skill/证据/治理」，产品与代码不共用。
幻觉？citations 为空直接 error；UI 必渲染原声。
接销售触达？话术过检后，才进 Sales Ops 预览→授权→群发。
