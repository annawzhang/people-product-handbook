3. Follow-up（面试追问怎么答）

追问答法要点
为什么不用大模型直接打分？初筛要可审计；关键词+证据是刻意选择。LLM 可做语义检索，但仍须回贴原文。
独立反馈和校准怎么配合？提交前不可见防锚定；提交后看平均分偏差识别偏宽松/偏严。
和 Greenhouse 差在哪？学的是结构化方法；公开版是教学复刻，无排班/邮件集成。
Agent 版如何防胡作非为？只能调白名单工具；引擎 throw 即对用户说「规则拒绝」。

5. Best practices

  • 开岗时和用人经理共同锁评分卡，之后不随意改权重「救」某个候选人。
  • 必备维度缺失只给「待定」，不要用其它维度高分掩盖。
  • 淘汰原因结构化（分析用），候选人沟通模板不写细节。
  • 每周看：初筛分档 vs 现场面通过率；若倒挂，先修评分卡。
  • Agent 输出必须带 tool 结果摘要，禁止无调用就下录用结论。

6. Demo 路径（建议 3 分钟）

  1. 打开看板 → 点超时候选人 → 看证据高亮与 knockouts。
  2. 切「我的面试」→ 不写满 15 字提交 → 看报错；写完后解锁他人反馈。
  3. 「职位与评分卡」拖权重 → 右侧名次箭头变化。
  4. 「招聘分析」看面试官偏宽松/偏严与分档通过率。
