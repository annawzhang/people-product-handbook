2. API / 引擎调用

Voice Agent（浏览器）

调用说明
VocAgent.answer(text)主入口；返回 text/blocks/citations 或 error
VocAgent.search(q, opts)按议题/车型/立场检索，点赞排序
VocAgent.topicStats(topic)按条/按点赞负面率 + Top 原声
VocAgent.priceCeiling()价位点负面点赞占比首次≥50%
VocAgent.fourStep(topic)认同→重构→转移→落地，绑定 cite
VocAgent.checkScript(text)禁止规则命中列表

Insight Kit（Python）

模块作用
voc.analyze去重、编码、情感、价格、人群
voc.scripts四步话术生成
config/codebook.toml议题关键词
config/scripts.toml话术与禁止规则

产品化 HTTP 建议

POST /v1/voc/query     { question } → { answer, citations[] }

POST /v1/voc/batch     { comments[] } → report_id   # Kit 跑批

3. Follow-up

追问答法
Agent 会不会幻觉？引擎层：citations 为空直接 error；UI 必须渲染引用。
为什么要点赞加权？防灌水；条数与加权两个口径一起看。
四步话术是否太死板？模板保底；禁止规则挡住危险发挥。
和销售触达如何衔接？话术过检后，才能进 Sales Ops 预览→授权→群发。

5. Best practices

  • 结论句旁必须有原声 ID；报告评审检查「无引用段落」。
  • 价格关口至少报告样本量；单条过半要标注「弱证据」。
  • 禁止话术规则配置化，业务可增删，不写死在模型里。
  • Agent 意图优先级：质检 > 话术 > 价格关口 > 议题检索。

6. Demo 路径

  1. Agent：点「价格心理关口」→ 看引用卡片。
  2. 生成四步话术 → 再「检查：保证提车+竞品垃圾」→ 看拦截。
  3. 打开 Insight 报告对比议题结论口径。
