5. Follow-up

追问答法
98008 和 Knot 是不是一回事？不是。98008 是入口产品名；Knot 是执行层主智能体；Console 是治理层。
VOC 公开版为什么没有 LLM？先把能力层与护栏做对：无引用拒答、禁止话术；产品化再挂模型，Skill 边界不变。
和 Gap Finder 怎么类比？98008：未命中→聚类→补 FAQ；VOC：批处理 Kit 更新语料/议题，Agent 只读证据。
子 Agent 和 Skill 区别？子 Agent = 业务域路由+专属书架；Skill = 可复用能力块（检索/风控/工单）。VOC 公开版用 Skill 白名单等价。
